`dice-table-flem0527.mp3` is the publicly available preview, not the original
24-bit WAV. The creator describes a pair of dice rolling on a wooden table.
The application uses an edited derivative: mono decode, silence trim, slight
slowing, soft limiting, loudness adjustment and short fades. Rebuild with
`python3 scripts/make-dice-audio.py` on macOS (uses system `afconvert`).
