Rollweave 隐私政策

更新日期：2026年9月29日

本政策适用于 Rollweave: Slot Atelier（以下简称“Rollweave”或“本应用”），说明本地游戏、在线网页、推送通知及广告效果衡量涉及的信息处理。

1. 本地游戏与存储

原生骰子游戏及规则工坊无须注册账号即可使用。玩家名称、游戏规则及标识、收藏、进度、成绩、历史记录、音效及触感偏好保存在设备上。原生游戏存储不会自动将这些记录上传至我们的服务器。您可以使用昵称。

本应用还保存应用内网页最近一次成功加载的完整网址，以便下次获取启动链接失败时使用。网址可能包含路径和查询参数。内嵌浏览器保存 Cookie、本地存储等网站数据，以支持网站会话。根据您的备份设置，iOS 设备备份可能包含应用数据。

2. 启动请求与网页内容

启动时，本应用向 ketwtyajxw.top 请求目标网址。请求中的“username”字段是固定的应用标识，并非您的个人用户名。与其他网络请求一样，接收服务可以获取您的 IP 地址及请求相关技术信息。

取得有效地址后，本应用通过内嵌浏览器打开网页；否则可能使用已保存的网址或进入原生游戏界面。在线网页可能自行发起请求，并处理网站使用信息、Cookie、账号信息或您主动填写的内容，具体取决于网站及您使用的功能。提交信息前，请阅读相应网页的隐私说明。

部分网页操作会打开系统浏览器。目标网站及浏览器服务按其适用政策处理信息。原生代码不会自动把本地游戏记录附加到这些链接中。

3. Firebase 推送通知

本应用使用 Google Firebase Cloud Messaging 和 Apple 推送通知服务注册并接收推送。此过程涉及应用安装标识、APNs 与 FCM 注册令牌，以及支持消息服务运行和诊断的技术信息。这些标识帮助服务将消息发送到相应应用安装实例。

当前原生实现不将 FCM 令牌绑定到已登录的游戏账号，也不将其上传至单独的开发者用户数据库，但 Firebase 仍会处理消息注册信息。本次接入未包含 Google Analytics SDK。

您可以在 iOS“设置 → 通知 → Rollweave”中允许或关闭通知提醒。拒绝或关闭提醒不会影响原生游戏，也不等于停止 Firebase 初始化或全部消息注册处理。

请参阅 Firebase 隐私与安全说明及 Google 隐私政策。

4. Meta 应用事件与跟踪选择

本应用使用 Meta（Facebook）SDK 衡量应用激活及广告效果。当网页向原生桥接发送受支持的事件时，本应用会向 Meta 传递购买、加入购物车、加入愿望清单或完成注册事件。涉及金额的事件包含金额及币种。这些事件名称不代表原生骰子游戏要求购买或注册。

原生事件桥接仅转发受支持的事件名称及校验后的金额、币种，不向 Meta 转发网页提供的可选姓名、电话、邮箱或用户 ID 字段。SDK 还可能按 Meta 政策及 SDK 披露处理应用与设备标识、技术信息、诊断信息，以及 IP 地址等网络信息。事件数据可能与设备或其他标识关联。

本应用通过 Apple 的 App Tracking Transparency（ATT）系统弹窗请求跟踪许可。您授权后，本应用会开启广告标识符（IDFA）采集，用于广告衡量与归因。您可以在 iOS“设置 → 隐私与安全性 → 跟踪”（较早版本为“隐私 → 跟踪”）中更改选择。

当跟踪被拒绝、受限制或尚未授权时，本应用不会开启 IDFA 采集。拒绝跟踪不会阻止您使用应用。权限状态确定后，事件仍可能按 SDK 的受限设置发送，Apple 的 SKAdNetwork 也可能用于保护隐私的广告归因。拒绝 ATT 并不等于关闭所有网络请求或全部分析。首次 ATT 选择尚未确定时，应用手动产生的事件会暂存在内存中等待处理。

有关 Meta 的数据处理及可用控制，请参阅 Meta 隐私政策。

5. 其他权限、导入与分享

原生实现不请求位置、通讯录、相机或麦克风访问权限。文件导入通过系统选择器访问您选择的文件。骰子音效仅用于播放，原生应用不进行录音。

分享游戏时，应用通过系统分享界面导出游戏名称、规则及格式信息，不包含独立玩家列表或成绩历史。您在游戏名称中填写的个人信息会随作品导出。接收方和服务由您选择，并按其自身政策处理分享内容。

6. 信息接收方与用途

启动链接服务及您访问的网站处理提供在线内容所需的信息；Apple 和 Google/Firebase 处理支持通知的信息；Meta 处理上述衡量信息。邮件服务商处理您发送的支持邮件。根据相关服务政策，信息可能在您所在国家或地区以外处理。

原生应用不向 Meta 或 Firebase 发送本地游戏库、玩家名称或对局成绩，但这不排除本政策说明的独立网页事件、标识及技术信息。适用法律要求时，我们也可能披露相关信息。

7. 保留、删除与您的选择

您可以在应用内删除已保存游戏，但不会自动移除之前的对局快照、历史成绩或恢复副本。要移除应用本地数据、网址缓存及其浏览器存储，请使用 iOS“删除 App”；“卸载 App”可能保留数据。已导出文件、设备备份及外部浏览器保存的数据需单独管理。

删除应用不会自动删除网站、Firebase、Meta 或其他接收方已经处理的信息。这些服务的保留期限和删除控制见其政策，我们不承诺所有服务采用统一保留期限。您可联系我们提出访问、更正或删除请求；我们会处理职责范围内的请求，并在可能时协助识别相关服务。请勿发送密码或支付资料。

8. 支持邮件与儿童隐私

您通过邮件联系我们时，我们会收到邮箱地址、邮件内容及附件，用于调查及回复问题，不用于广告。我们按处理咨询及相关后续事项的需要或法律要求保留邮件，您可以请求删除。

原生游戏不要求真实姓名或年龄，在线服务有其自身的使用资格要求。如果您认为儿童通过本应用或相关服务提供了个人信息，请联系我们，以便调查并处理我们职责范围内的信息。

9. 安全与政策更新

本应用利用 iOS 应用隔离及系统存储保护机制。请保护设备访问权限，并谨慎选择在网页输入或对外分享的信息。任何存储或传输方式均无法保证绝对安全。

应用及数据处理方式变化时，我们可能更新本政策和上方日期。适用要求规定时，我们会另行告知或征得同意。
