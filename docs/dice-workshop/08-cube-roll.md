# 六面骰子翻滚与音效 · 2026-09-21

本轮替换上一版仅倾斜正面的动画。

**当前音效已换为真实骰子录音，见文末“真实录音版”。前面的合成音说明保留为迭代记录。**

- 使用系统 `CATransformLayer` 和六张代码绘制的骰面组成完整立方体；相对两面的点数相加为 7。
- `CADisplayLink` 按时间计算多轴完整旋转，避免矩阵插值只走最短路径。先快速翻滚，再减速、轻微弹跳并稳定；单颗约 1.2 秒，多颗错开 35ms。
- 正面始终分配为引擎已保存的最终值；动画只旋转几何体，不生成随机结果、不改变得分。
- 重掷只转动指定骰子，保留骰子静止；减少动态效果时显示静态立体骰子并短淡入。
- 新增原创合成的骰子滚动/碰撞短音效 `Dundaillereal/Resources/dice-roll.wav`（44.1kHz、单声道、16 位 PCM、1.36 秒），由 `scripts/make-dice-audio.py` 可重复生成。
- 音效通过 `AVAudioPlayer` 播放，遵守“投骰声音”开关；使用 ambient 音频类别，遵守静音开关并与其他音频混音。离开或切后台会停止声音与逐帧动画。
- 没有引入第三方框架，没有使用物理引擎决定点数，没有修改规则和存档格式。

声音为合成桌面碰撞效果，不是录制素材；真机扬声器、静音开关与音量体验仍需真机确认。

## 音色调整

根据“声音太清脆”的反馈，改为衬垫木质骰盘的短促闷响：主体共振下移到 235/421 Hz，少量 683 Hz 保留触地质感；噪声经过两级 1100 Hz 低通，起音软化，尾音保持短促。每次碰撞有轻微音高差异，避免重复电子提示音感。保留原有 1.36 秒长度与落点节奏，播放开关和动画逻辑未改动。

新音频峰值约 0.220（原约 0.397），没有削波，首尾采样为零；脚本重复生成文件一致。Debug 构建通过，已核对应用包中的 WAV 与新资源一致。上方预览已更新为新音轨，按应用的 0.8 播放音量混入。真机声音体验仍未实测。

## 真实录音版（当前）

用户反馈柔和版太轻，进一步从网上查找木桌投骰实录。采用 [Flem0527 — Dice Rolling on Table](https://freesound.org/people/Flem0527/sounds/629982/) 的公开 HQ 试听素材，来源页面标注 CC0；原始来源、许可及编辑方式保存在 [素材说明](../../scripts/audio-sources/README.md)。素材是一对骰子在木桌上的实际滚动录音。

现在的 `make-dice-audio.py` 使用 macOS 系统 `afconvert` 解码该素材，去除开头静音、轻微放慢到匹配动画时长，保留不规则碰撞和自然收尾，通过软限幅提升持续滚动细节的响度。最终仍为 1.36 秒单声道 PCM，峰值 0.850、RMS 0.090（约 -20.9 dBFS），相比上一版 RMS 提高约 11.7 dB，没有数值削波，首尾为零。播放音量保持 0.8。

减少动态效果时从 0.06 秒的清晰碰撞处开始播放，替代原先 0.90 秒的安静尾音；静音开关与应用声音设置继续生效。Debug 构建通过；已核对资源与应用包一致、再生成文件一致，并更新上方预览音轨。本轮未重复 UI 全流程测试，真机听感未实测。
