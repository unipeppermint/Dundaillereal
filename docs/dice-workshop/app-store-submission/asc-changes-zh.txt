一、App Privacy（App 隐私）：更新并发布

“Do you or your third-party partners collect data from this app?” 选择 Yes。
ATT 授权后存在 Meta 广告衡量，不能选 Data Not Collected 或声明完全不跟踪。
以下是当前应用和随包 SDK 隐私清单合并后的填写基线，不是抓包结论。最终 Archive 后用 Privacy Report 和实际采集复核；确认某项确实不采集后才能删除。

1. Identifiers > Device ID
   Purposes: Third-Party Advertising; Developer's Advertising or Marketing; Analytics; App Functionality
   Linked to the user's identity: Yes
   Used for tracking: Yes
   来源：Meta 标识符、Firebase/APNs 安装及推送标识。
   Third-Party Advertising 来自随包 Meta 隐私清单；Developer's Advertising or Marketing 对应本应用推广衡量。FCM 单独不跟踪，但不能覆盖同一类别中 Meta 的用途。

2. Usage Data > Product Interaction
   Purposes: Analytics; Developer's Advertising or Marketing
   Linked to the user's identity: Yes
   Used for tracking: Yes
   来源：安装/激活衡量。不是上传游戏规则、分数或购买记录。

3. Diagnostics > Crash Data
   Purposes: App Functionality
   Linked to the user's identity: No
   Used for tracking: No
   来源：随包 Meta SDK 声明。不能因未接入 Crashlytics 就省略。

4. Diagnostics > Other Diagnostic Data
   Purposes: Analytics; App Functionality
   Linked to the user's identity: No
   Used for tracking: No
   来源：Firebase Installations、Messaging、GoogleDataTransport 声明。

5. Other Data > Other Data Types
   Purposes: Analytics
   Linked to the user's identity: No
   Used for tracking: No
   来源：Meta 与 Firebase Messaging 声明。

3—5 的“不关联/不跟踪”来自 SDK 的声明；若实际日志将其关联到设备，则按实际调整。
隐私地址接口与网页托管方的日志保留及 IP 用途尚未通过服务端配置核实，应合并实际保留的数据；隐私网页不自动豁免披露。
当前代码没有购买历史、精确定位、通讯录、照片、音频或广告展示交互数据的采集证据，不因使用 SDK 就随意勾选这些类别。
纯本地昵称、规则、存档、成绩不作为离开设备被收集的数据申报。用户主动分享及支持邮件要结合实际接收方式和 Apple 可选披露条件判断。
ATT 获准后才采集仍需披露；无账户不等于数据不关联用户。

六、Age Rating（年龄分级）

Messaging and Chat：No，本地欢迎消息不是用户之间通信。
Advertising：只做 Meta 归因、不在应用内展示付费推广时可选 No；App Privacy 中 tracking 为 Yes 不矛盾。
Gambling：No，原生游戏没有真钱或可兑现金投注。
Simulated Gambling：当前玩法没有下注机制时选 None；不能仅因骰子或 Bank or Bust 名称判定为模拟赌博。
Loot Boxes：No。
User-Generated Content / Social Media：当前没有公开发布或内容流；本地编辑和系统文件分享不等于公开 UGC 平台。
Contests：本地多人按游戏得分比较结果，按问卷竞赛定义核对；若作为主要、反复出现的对战玩法，按 Frequent 频率填写，不能直接沿用旧“全部 None”。
Unrestricted Web Access：固定政策页不自动等于自由浏览器；但当前 WebView 未限制域名，不能仅按业务用途确认 No。按实际可导航范围回答，或先限制为所需隐私页面。
最终年龄由完整问卷生成，不承诺一定为 4+。
