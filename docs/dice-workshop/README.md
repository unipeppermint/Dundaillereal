## 已确定的方向

- 暂定产品名：骰子工坊。名称尚未进行商标和商店重名核验。
- 首版离线运行，支持单人及 2～4 人共用一台手机轮流游玩。
- 核心流程：直接开局 → 理解规则 → 改编规则 → 试玩 → 分享作品文件。
- 三个主导航：游戏桌、工坊、收藏柜。
- Swift + UIKit，iPhone 竖屏，最低 iOS 16，优先使用系统框架。
- 先完成《恰好到站》的完整闭环，再扩展模板和工坊。
- 实时联机、社区、云同步、AI 生成规则、完整 3D 物理不在首版范围。
