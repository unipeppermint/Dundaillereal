# 投骰动效与立体质感 · 2026-09-21

本轮只修改 UIKit 呈现与 UI 测试，没有更改规则、随机源或存档格式。

- 骰子增加象牙色底边、厚度、高光、凹点边缘和投影；点数仍按引擎结果准确绘制，没有贴图替换真实结果。
- 投骰/重掷先由引擎计算并完成原子保存，再进入“投掷中…”呈现。摇动、腾起、带透视的旋转、落桌轻弹按骰子错开约 35ms，主动作约 0.6～0.8 秒，随后淡出回到棋盘。
- 仅动画化此次实际重掷的骰子；保留骰子在呈现区静止。
- 动画期间拦截重复游戏动作，落稳后才更新合计、解释及操作区。开局投骰和冒险投骰共用此流程。
- 切后台或离开页面立即取消动画、待执行反馈及完成回调；展示已保存结果，不重抽、不重复计分。
- 开启系统“减少动态效果”时使用短淡入淡出，避免腾起/旋转。声音、触感仍遵守设置开关，落桌时触发。

## 验证

Xcode 26.6 / iOS 26.5 / iPhone SE 第 3 代：

1. 工坊编辑、保存、试玩结算通过。
2. 正式六轮对局、投骰后重启恢复通过。
3. 新增单颗重掷检查通过：等待呈现退出，确认另外两颗点数未变、仅消耗一次额度。

第一次 iPhone 17 Pro 测试停在旧应用进程终止，未进入业务流程，已停止该轮并在独立小屏幕设备运行验证。新增测试首轮在动画结束前断言界面，改为显式等待呈现结束后通过。

最终包含间距收尾的 Debug 构建与新增重掷测试通过。减少动态效果分支与后台取消路径已实现，但本轮没有自动化验证动画中途切后台或系统减少动态设置。声音及触感的实际体验仍需真机确认。
